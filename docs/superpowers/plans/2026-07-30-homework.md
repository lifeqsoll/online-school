# Homework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement assignments (LESSON/MODULE/COURSE), CHOICE/SHORT auto-grade + OPEN manual grade, multi-attempt submissions, per-course XP with best-attempt sync, and course leaderboard — testable via HTML/Postman/e2e.

**Architecture:** Nest modules `assignments`, `submissions`, `xp`. Postgres via Prisma; reuse `CourseAccessService`, audit, sanitize. XP via `AssignmentBestXp` + `XpBalance` + `XpLedger`. No Topics/Neo4j in this slice.

**Tech Stack:** NestJS 11, Prisma 7, existing JWT/RBAC, Jest unit+e2e, Docker Postgres/Redis.

**Spec:** `docs/superpowers/specs/2026-07-30-homework-design.md`

## Global Constraints

- Backend-only; extend `public/` HTML stubs — no React app.
- Assignment always has `courseId`; scope FKs match `LESSON`|`MODULE`|`COURSE`.
- Never return `correctKeys` to students.
- XP only when submission is `AUTO_GRADED` or `GRADED`; best attempt via `AssignmentBestXp` (delta may be negative on regrade).
- `maxAttempts` null = unlimited.
- PUT questions rejected if any submission exists.
- Follow Catalog patterns (`CourseAccessService`, audit actions, DTOs).
- Do not implement Analytics/Topics/Neo4j outbox here.
- Commit after each task on `feature/foundation-auth`.
